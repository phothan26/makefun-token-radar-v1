Methodology — how every number is made

Every figure on this page is derived from the sealed snapshot's own numbers. Nothing is a hand-kept list: the same snapshot always produces the same board.

score = ( 10·ln(TVL / $1M) + 8·clamp(7d change, −25%, +50%) / 50 + 1.2·min(years listed, 6) + 2.5·ln(1 + min(chains, 20)) ) × category multiplier + 12 if no token is recorded

The category multiplier comes from that category's median TVL in the snapshot (0.80–1.25): categories whose protocols are typically larger price a little higher. The no-token bonus is what lifts protocols still waiting for a launch above the 416 tokened ones, which are set aside and never ranked — the board is the pre-token universe only.

implied value = 10^(6.3 + 3.0 × normalised score), so the top row lands near $2B and the bottom near $2M. Scale dominates on purpose: a venue holding $13B would issue a far larger token than a $8M protocol, whatever its category. Use the category filter to compare within one kind of protocol.

Each farm plan is generated from the protocol's own category, chains and scale — a DEX plan is not a lending plan — and every step says what to do, what it costs and how long it takes.

Implied values are this radar's own estimates, not predictions and not promises. A protocol that records no token may still have one its record does not carry.
